# Pizza Sales SQL Project

Analyzes pizza orders and sales data using MySQL to identify revenue trends, 
best-selling pizzas, customer ordering patterns, and product performance.

## Tables
- `orders` — order id, date, time
- `order_details` — order line items, pizza id, quantity
- `pizzas`, `pizza_types` — pizza catalog info

## Tools Used
MySQL 8.0, MySQL Workbench
